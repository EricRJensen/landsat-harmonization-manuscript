# Landsat sensor harmonization

Source code for *Cross-Sensor Differences in Landsat Collection 2 Vegetation
Indices Alter Environmental Inference* (manuscript dated September 4, 2026).

The repository contains the scripts used to generate the paired Landsat sample,
fit the harmonization relationships, produce the manuscript figures and tables,
and run the Landsat Harmonization Explorer. Large analysis inputs and generated
figures are not stored in Git.

## Analysis scripts

Run scripts from the repository root. File paths that a user may need to change
are defined near the top of each R script. The Earth Engine JavaScript files are
intended to be copied into the [Earth Engine Code Editor](https://code.earthengine.google.com/)
and run there.

| Script | Manuscript use |
|---|---|
| `leohs_generate_samples.py` | Generate paired ETM+/OLI samples |
| `leohs_generate_ids.py` | Add stable identifiers to sample exports |
| `leohs_extract_covariates.py` | Extract and join analysis covariates |
| `figure_01_extract_grsa_timeseries.js` | Export the GRSA annual Landsat series |
| `process_figure_01_grsa_export.R` | Reshape the GRSA export |
| `figure_01_sensor_bias_and_grsa_timeseries.R` | Figure 1 |
| `figure_02_s01_s03_tables_01_s05_harmonization.R` | Figure 2, Figures S1-S3, Tables 1 and S5 |
| `tables_s01_s02_bias_by_ecoregion.R` | Tables S1-S2 |
| `tables_s03_s04_view_geometry.py` | Tables S3-S4 |
| `figure_03_s04_extract_park_trends.py` | Export park trend inputs |
| `figure_03_s04_plot_park_trends.R` | Figures 3 and S4 |
| `figure_04_extract_greatbasin_landsat.js` | Export the regional Landsat series |
| `figure_04_extract_greatbasin_spei.js` | Export the regional SPEI series |
| `figure_s05_s06_extract_greatbasin_landsat_sensor.js` | Export sensor-specific regional series |
| `figure_04_s05_s06_hydroclimate_sensitivity.R` | Figure 4 and Figures S5-S6 |
| `figure_05_extract_sims_fields.py` | Export annual SIMS field values |
| `figure_05_sims_sensitivity.R` | Figure 5 |

Shared R functions used for index calculation, sample selection, model fitting,
and validation are in `analysis/common/manuscript_methods.R`.

## Paired Landsat sample

The analysis-ready paired-sample file is not stored in this repository. It will
be published as `SR_Landsatsamples_Covariates.parquet` in the following Zenodo
record, which is still a draft:

https://zenodo.org/records/22033662

Place the downloaded file at:

```text
data/external/SR_Landsatsamples_Covariates.parquet
```

The file used for the manuscript contains 4,820,405 rows and has SHA-256:

```text
a2ef688d76bebc9f3be71b6dcb7e675380192c6df063141e44c9bfbdbe1b6e95
```

The `leohs_*` scripts document how paired samples and covariates were produced.
They do not provide a bit-for-bit reconstruction of the archived parquet because
the random seeds and exact merge command for the two original LEOHS runs were
not retained. See `REPRODUCIBILITY_NOTES.md` for additional details.

## Other analysis inputs

The remaining inputs are generated by the corresponding extraction scripts and
should be placed under `data/external/` using the filenames defined near the top
of the analysis scripts. They are not distributed with this repository.

- Figure 1 uses the GRSA Landsat CSV exported by
  `figure_01_extract_grsa_timeseries.js`.
- Figures 3 and S4 use the park trend GeoTIFFs exported by
  `figure_03_s04_extract_park_trends.py` and an NPS boundary file.
- Figures 4, S5, and S6 use the Landsat and gridMET-DROUGHT exports produced by
  the three Figure 4 Earth Engine scripts.
- Figure 5 uses the annual field CSV produced by
  `figure_05_extract_sims_fields.py`. Its harmonized SIMS collection is
  restricted and is not constructed in this repository.

## Software

Python dependencies for the analysis scripts are listed in `requirements.txt`.
LEOHS must be installed separately to regenerate paired samples. The archived
run logs identify LEOHS 1.1.2, while the manuscript currently states 1.2.0.

The R scripts use `arrow`, `dplyr`, `ggdist`, `ggplot2`, `ggrepel`, `hexbin`,
`patchwork`, `purrr`, `readr`, `scales`, `sf`, `terra`, `tidyr`, and
`tidyterra`.

The explorer app has separate setup and deployment instructions in `app/README.md`.
Its regional coefficient collection was built for a broader set of use cases
than the manuscript-specific analysis.
