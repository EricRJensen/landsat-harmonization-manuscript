# Image sources

- `landsat-banner.png`: graphic supplied by Eric Jensen on October 19, 2026. Used unchanged as the header background, with CSS overlays for text contrast.
- `dri-logo.png`: official DRI logo downloaded from the [DRI website](https://www.dri.edu/wp-content/uploads/DRI-logo-taglineWEB2.png) on October 19, 2026. The original transparent image is preserved; the footer frame crops only its transparent padding.

- `landsat-footer.png`: “Seasonal creek through shifting grassland” graphic supplied by Eric Jensen on October 19, 2026. Used unchanged in the footer and welcome modal, with light CSS overlays for text contrast.

- `landsat-favicon.png`: “Satellite_Shield_Transparent” graphic supplied by Eric Jensen on October 19, 2026. Used unchanged as the browser favicon, preserving its transparency.

- `landsat-banner.webp` and `landsat-footer.webp`: existing compressed copies of the banner/footer artwork, copied from the companion website's `landscape-dark.webp` and `landscape-light.webp`. Same dimensions and compositions as the PNG originals, now used by the Explorer to reduce image transfer from 5.4 MB to 0.6 MB.
